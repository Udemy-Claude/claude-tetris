❯ dame una breve explicacion del archivo game                                   

  Thought for 4s, read 1 file (ctrl+o to expand)

● game.js (~307 líneas, vanilla JS, sin dependencias). Organización:

  Constantes (1-29): Tablero 10×20, block size 30px. 7 piezas definidas como
  matrices (I/O/T/S/Z/J/L) con colores. Puntuación por líneas: 100/300/500/800.

  Estado global (43): board, pieza current/next, score, líneas, nivel, pause,
  gameOver, loop timing.

  Lógica core:
  - createBoard() — Matriz 20×10 de ceros.
  - randomPiece() — Pieza aleatoria con posición inicial centrada.
  - collide() — Detecta colisiones con bordes y bloques fijos.
  - rotateCW() + tryRotate() — Rotación horaria con wall kicks (±1, ±2).
  - merge() — Fija pieza actual al tablero.
  - clearLines() — Elimina filas completas, actualiza score/nivel. Velocidad
  base 1s, reduce 90ms por nivel, mínimo 100ms.
  - ghostY() + hardDrop()/softDrop() — Posición fantasma y caídas.
  - spawn() → lockPiece() — Ciclo de vida de cada pieza.

  Renderizado:
  - drawBlock() — Bloque individual con highlight superior.
  - drawGrid() — Líneas de cuadrícula.
  - draw() → ghost (20% opacidad) + tablero + pieza actual.
  - drawNext() — Vista previa en canvas separado.

  Game loop (243-257): requestAnimationFrame con acumulador delta-time. Drop
  cuando dropAccum >= dropInterval.

  Input (277-303): Flechas mover/rotar, Space hard drop, P pausa. Game Over si
  pieza nueva colisiona al spawn.

  init() (259-275): Resetea todo y arranca loop.

❯ dame una explicacion de las constantes                                        

  Thought for 2s (ctrl+o to expand)

● Las constantes al inicio del archivo (líneas 1-29):

  COLS = 10, ROWS = 20, BLOCK = 30 — Dimensiones del tablero: 10 columnas × 20
  filas, cada bloque de 30×30 píxeles en el canvas. Estándar de Tetris.

  COLORS — Array de 8 elementos (índice 0 = null, índices 1-7 mapean a cada
  pieza). Cada color es un tono Material Design pastel: cyan (I), amarillo (O),
  púrpura (T), verde (S), rojo (Z), índigo (J), naranja (L).

  PIECES — Array con las 7 piezas definidas como matrices de 0s y 1s (índice del
  color). Cada matriz representa la forma en su rotación inicial:
  - I — 4×4, línea horizontal.
  - O — 2×2, cuadrado (única que no rota realmente).
  - T/S/Z/J/L — 3×3, formas estándar del Tetris.

  El valor numérico en cada celda de la matriz coincide con el índice en COLORS,
  así que PIECES[3][1][1] = 3 = color púrpura = pieza T.

  LINE_SCORES = [0, 100, 300, 500, 800] — Puntos base por líneas eliminadas: 0
  (ninguna), 100 (1 línea), 300 (2), 500 (3), 800 (4, Tetris). El score real se
  multiplica por el nivel actual.
